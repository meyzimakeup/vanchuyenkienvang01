# Landing page — Vận Chuyển Kiến Vàng

## Cách sử dụng
1. Giải nén thư mục.
2. Mở `index.html` bằng trình duyệt để xem thử.
3. Khi đưa lên hosting, tải lên cả `index.html` và thư mục `images` để hình xe hiển thị đúng.

## Chuyển đổi Zalo
Các nút liên hệ mở `https://zalo.me/0969563566`. Form tạo nội dung yêu cầu, mở Zalo và cố gắng sao chép nội dung để khách chủ động gửi.

## Tùy chỉnh
Mở `index.html` bằng VS Code hoặc trình soạn thảo để sửa nội dung, dịch vụ, màu sắc và thông tin liên hệ.
